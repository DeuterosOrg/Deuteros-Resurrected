# Contributing

Thanks for helping bring Deuteros back. This is a faithful remake of Ian Bird's
1990 Amiga/Atari ST game, released under [CC0 1.0](LICENSE).

Maintainers can push straight to `develop` or open a pull request, whichever
suits. Outside contributors please send a pull request from a fork. There is
no required branch layout, label set, or commit / PR title format.

Please search existing issues before opening a new one. A short bug form is
available, or you can open a blank issue. For fidelity gaps (the remake
behaves differently from the original), mention your evidence if you have it.
Never post security problems in a public issue — see [SECURITY.md](SECURITY.md).

By contributing you agree your contribution is released under CC0 1.0.
Third-party material keeps its own licence; say so in the PR.
